# Playbooks

Tài liệu, hướng dẫn và kinh nghiệm thực tế của mình về làm sản phẩm phần mềm với AI, chia sẻ cho bạn bè và cộng đồng dev Việt Nam.

Viết bằng tiếng Việt, giữ thuật ngữ kỹ thuật bằng tiếng Anh. Ngắn gọn, có prompt mẫu để dùng ngay.

## Mục lục

| Tài liệu | Nội dung |
| --- | --- |
| [Dùng Claude xây dựng sản phẩm từ ý tưởng](guides/claude-tu-y-tuong-den-san-pham.md) | 9 giai đoạn từ ý tưởng đến app phát hành: kiểm chứng thị trường, PRD, kiến trúc theo quy mô, UI/UX, Claude Code, test, deploy. Ví dụ Flutter + Go/FastAPI + PostgreSQL |
